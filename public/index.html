评分方法透明、可追溯

综合分 = 连通成功率 ×10% + 目录成功率 ×15% + 补全成功率 ×25% + 流式成功率 ×25% + 并发成功率 ×25%。每项都是「SLA 内达标次数 / 尝试次数」：连通 TTFB ≤3000ms、目录 ≤5000ms、补全 ≤10000ms、流式首个 token ≤10000ms、并发整轮 ≤30000ms，超出时限算失败，未测到的维度按 0 计。等级按 90 / 80 / 70 / 60 分档。

本站为中转站测评榜单的自建版本，榜单数据全部保存在本地 JSON，不依赖第三方服务；评分只反映该站点的维度实测与登记数值。
